# Shri Vasavi Stores and Essence Mart

A clean, mobile-friendly product catalog for bakery supplies and daily essentials.

## Preview

Open `index.html` from a local web server or an HTTPS host. The public catalog loads from Supabase. Approved managers sign in with their Supabase email and password to add or remove products.

The starter list is sample information for preview when cloud data is unavailable. Replace sample prices and quantities with real inventory before showing it to customers. The app needs the SQL schema and multi-owner migration applied to the configured Supabase project, plus at least one manager account added to `shop_owners`.

## Product scope

Bakery supplies such as cake boxes, sweet boxes, essence, candles, and food colour; tea powder, milk powder, Horlicks, Boost, tea cups and glasses; dal varieties and pickles; plus household and personal care essentials. The catalog intentionally excludes vegetables, fruits, eggs, liquid milk, and ready-to-eat bakery products.
